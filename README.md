# CaseZero — AI Detective

CaseZero is an immersive cinematic AI investigation game based on a fictional mystery called **The Missing Prototype**.

The player takes the role of an investigator inside Aether Dynamics Laboratory and must examine evidence, interrogate suspects, connect clues, and make the final deduction.

## 🕵️ The Case

A valuable energy-harvesting prototype called **HELIOS** has disappeared from a restricted laboratory vault.

Three people are under investigation:

- Dr. Elena Vasquez — Lead Engineer
- Marcus Chen — Security Chief
- Dana Whitlock — Night Supervisor

The investigator must determine:

- Who took the HELIOS prototype?
- How was it taken?
- Was anyone else involved?

## 🎮 Features

- Cinematic investigation interface
- Evidence Locker with physical and digital evidence
- Suspect interrogation system
- Case File for connecting clues and investigation entries
- Final deduction system
- Multiple evidence-based investigation stages
- Interactive mystery storyline

## 🛠️ Tech Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- JavaScript
- AI-assisted development with Whispr Flow
